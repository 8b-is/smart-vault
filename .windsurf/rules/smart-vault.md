# smart-vault: Windsurf rules

Read `AGENTS.md` as the canonical host-neutral contract. Preview and link Cascade skills with:

```bash
smart-vault setup-host --host windsurf --workspace "$PWD"
smart-vault setup-host --host windsurf --workspace "$PWD" --apply
```

Connect `smart-vault mcp` for agent-agnostic vault search, Smart Tree navigation (`st`), parallel CSR graph lint, MemNet `MEM|8` wave memory, and MemPalace retrieval.
